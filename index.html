個人 AI Relay 設定（選填）

「統整最終筆記」「模擬考出題／評分」「掃描筆記／圖片辨識」會使用你自己的 GPT／Claude API 帳號。這個網站只儲存 Relay 網址與保護密碼；真正的 API Key 只放在你自己的 Cloudflare Worker Secret，不會放進 GitHub 或這個網頁。每次使用 AI 都會消耗該 API 帳號的 token／額度；ChatGPT Plus、Claude Pro 訂閱不包含 API 額度。

第一次設定怎麼做？
  1. 到 OpenAI API 或 Anthropic Console 建立自己的 API Key，並確認 API 帳號有額度。
  2. 將本專案的 cramgoose-ai-relay-worker 資料夾部署到自己的 Cloudflare Worker；把 API Key 設為 Secret。
  3. 將 Cloudflare 產生的 https://...workers.dev 網址與你設定的 Relay 密碼填回此處，按「測試並儲存」。
